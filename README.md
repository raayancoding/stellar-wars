# Stellar Wars: Last Defense

A complete browser-based arcade space shooter — 30 campaign sectors, evolving bosses, endless survival, a weekly boss, ship upgrades, skill trees and procedural audio.

## Controls

| Action | Desktop | Touch |
| --- | --- | --- |
| Move | `WASD` / arrow keys, or hold mouse/touch on the playfield | Virtual joystick (bottom-left) |
| Fire | Automatic | Automatic |
| Missiles | `Q` / missile button | Missile button |
| Ship ultimate | `E` / ability button | Ability button |
| Nuclear Blast | `R` | Power column |
| Orbital Strike | `F` | Power column |
| Time Slow | `G` | Power column |
| Pause | `Esc` / `P` | Pause button |

Pickups drop from destroyed enemies: weapon boosts, shields, hull repair, coins, freeze, missiles, speed, coin surge, invincibility and the black hole.

## Features

- **Campaign** — 30 sectors with scripted wave plans, mini-bosses and multi-phase final bosses.
- **Endless** — survive escalating waves, mini-boss every 3rd wave and a boss every 5th; the run continues after each boss.
- **Weekly boss** — one signature target per ISO week with a score leaderboard entry and a one-time clear bonus.
- **Boss Rush** — five escalating bosses back to back with no wave breaks and scaling rewards.
- **Daily Challenge** — a date-seeded campaign-like mission, identical for every pilot on a given day.
- **Training Simulator** — invulnerable endless practice with no save rewards.
- **Garage** — 8 hulls (Scout, Fighter, Destroyer, Titan, Phantom, Interceptor, Gunship, Dreadnought) with five upgrade lines each and per-ship ultimates.
- **Store** — weapons (laser, dual/triple cannons, plasma, beam, railgun, missile pods), defense, utility, drones and premium powers.
- **Skill tree** — 18 nodes across six branches (Bulwark, Payload, Overcharge, Predator, Fleet Command, Engineering), one point per sector clear.
- **Companion drones** — attack, shield and repair wingmen; the attack drones engage targets on their own.
- **Galaxy map** — a 30-node star route with per-sector status, star records and a fleet statistics panel.
- **Achievements** — 25 bronze-to-platinum awards tracked across every mode.
- **Cosmetics** — hull paints and engine-trail colours per ship.
- **Progression** — star ratings (3 stars for ≥75% hull with no emergency cores used), credits, daily supply drop, pilot stats.
- **Graphics** — cinematic post-processing (FXAA, bloom, ACES tone mapping, vignette, chromatic aberration, grain, sharpen) with a low-quality mode for weaker GPUs.
- **Juice** — pooled particle FX, debris, shield impacts, shockwaves, glow layer, screen shake, banners, combos, procedural music/SFX, starfield parallax.
- **Responsive** — desktop, portrait and landscape phone layouts with a dedicated joystick HUD.
- **Save** — autosaved to `localStorage` under `stellarwars.save.v2`; portable export/import codes in Settings.
- **Offline** — a service worker caches the shell and assets after the first visit.
